# Product Owner: Prompt Engineering Workshop

This repo contains the content for a prompt engineering workshop. The focus of this material is to give product managers a use-case-based approach to prompt engineering to spend less time doing the rote boring work and more time doing work where they bring their intellect to the table.

## Structure

The workshop is structured in 4 parts which each build upon each other. Each section has a short explanation of the material in it. 

The workshop has been designed to be run in Microsoft Copilot. It's not my favourite of the LLM playgrounds, but it is one that most people in corporate have access to. The final section `MS Copilot` shows how to use agent mode in MS Copilot. I find this to be the most promising, although the last time I used it, it was still a little finicky. 

The first parts of the workshop have been designed to be used with normal chat mode. The instructions part can look a bit ugly at the beginning of the messages, but it helps to get the point across that we can give our agents a personality. This is more obvious when building an Agent.
